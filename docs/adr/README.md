# Architecture Decision Records

This directory records durable engineering decisions for the SHARC reference
implementation. ADRs should describe the context, decision, alternatives,
consequences, and reversibility of choices that affect release engineering,
public contracts, build policy, or long-lived architecture.

Use a numbered filename (`0001-short-title.md`) and keep status current:
`Proposed`, `Accepted`, `Superseded`, or `Rejected`.

ADR filenames and numbers are permanent. If a later decision replaces an older
one, leave the old ADR in place and mark its status as `Superseded`, with a
link to the replacement.
