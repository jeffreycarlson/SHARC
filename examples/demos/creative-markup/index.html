SHARC Creative Markup demo

Local node server.cjs page that exercises the renderer protocol against the canonical reference renderer.

Test / dev only. This demo MUST be served via node server.cjs (or any HTTP origin). It will NOT work via file:// — browsers refuse ES module imports from the file scheme. The demo also depends on the KNOWN_TEST_RENDERERS guard recognizing the host as a dev origin (localhost / 127.0.0.1 / *.localhost / *.test / *.local / [::1] / 0.0.0.0). See docs/proposals/creative-sources.md § Renderer Ownership Model.
