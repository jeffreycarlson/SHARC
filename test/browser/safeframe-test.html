How this works:
The container loads safeframe-wrapper.html which provides window.$sf.ext via the SHARC bridge before the creative runs. The SafeFrame creative uses only standard $sf.ext APIs — it has no knowledge of SHARC.

Key differences from MRAID:
• SafeFrame has a single registered callback (not a listener map)
• First callback fires on stateChange(active) as 'geom-update'
• $sf.ext.cookie() fires 'failed' immediately
• $sf.host is intentionally absent
